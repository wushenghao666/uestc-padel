# UESTC Padel

一个面向手机端的 Padel / 板式网球 Americano 活动计分 MVP。

## 当前功能

- 球员无需登录即可创建活动、报名、编辑和删除报名信息。
- 管理员登录后可以编辑和删除活动，也可以退出登录。
- 当前支持 4 人转转赛，自动生成：
  - AB vs CD
  - AC vs BD
  - AD vs BC
- 支持抢分和局制计分；局制在排行统计中按 4 倍分数计算。
- 活动开始后报名信息锁定，任何人都可以编辑比分。
- 活动可以设置开始时间和结束时间，结束时间后比分锁定。
- 活动内排行按胜场数、净胜得分、总得分排序，完全相同时并列。
- 总排行榜显示每个球员姓名的参加活动次数、积分、总得分，并支持切换排序。
- PWA 基础配置，支持浏览器安装和离线缓存静态资源。

## 使用

核心功能可以直接用浏览器打开 `index.html` 使用。

如果要测试 PWA 安装和离线缓存，建议在项目目录启动一个本地静态服务：

```bash
python -m http.server 4174 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4174/index.html
```

管理员默认密码：

```text
uestc
```

## 数据持久化

当前版本使用浏览器 `localStorage` 做本地持久化，适合先把业务流程跑通。

后续接免费共享云端存储时，建议把 `app.js` 里的 `loadState()` 和 `persist()` 替换为 Supabase、Firebase 或类似服务的读写方法，其余计分和排行逻辑可以继续复用。
